# 任务概览：咖啡冲煮记录 · 产品推广方案话术

## 做了什么
按璐哥工作流（洞察 → 定位 → 文案 → 话术 → 节奏）产出一份完整的推广方案话术手册（HTML）。

## 核心决策
- **核心洞察**：每个手冲用户都冲出过一杯"绝世好咖啡"然后永远失去——围绕这个懊悔时刻建立全案冲突轴。
- **主文案**："会冲的人很多，记得住的人很少。"（品类占位句式）；首推 Slogan："让好喝，可以重来。"
- **产品角色定位**：不做"记录工具"，做"私人冲煮教练"——把"偶尔好喝"变成"杯杯好喝"。
- **交付内容**：洞察弹药库、5 条 Slogan（标注技巧）、核心文案组、小红书/短视频/详情页场景话术、门店与豆商渠道话术+异议处理、四阶段 Campaign 骨架（UGC 共鸣 → 引入 → 打卡养成 → 年度报告扩散）。

## 交付物
- 咖啡冲煮记录-产品推广方案话术.html（工作区根目录）
